# SuperBoard Lite

Boards of snapshot widgets that refresh on a schedule and keep history. A practice project for an agent-driven plan → design → build → test → deploy → maintain workflow.

Not affiliated with the SuperBoard product that inspired the idea.

```
pnpm install
pnpm dev          # local dev server
pnpm check        # lint + typecheck + unit tests
pnpm test:e2e     # Playwright (run `pnpm exec playwright install chromium` once)
```

Agents: start with `AGENTS.md` and `docs/ai/state.md`.
